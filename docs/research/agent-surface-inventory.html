4Port candidates, ranked by asymmetry

  1. Global instructions → Pi and Copilot. Both run blind. Copilot wants ~/.copilot/copilot-instructions.md; Pi has no user-level file at all. Beads and RTK policy is the obvious payload.
  2. Copilot's 14 CE skills → Claude/OMP, or unify on one CE version. Two vintages coexisting is the messiest item in this inventory.
  3. Signet skills → Pi (9 skills) if memory/recall parity is wanted. Otherwise accept Claude-only and stop half-integrating.
  4. ~/.agents/AGENTS.md is a template stub occupying a 12000-token startup budget in Claude. Fill it or drop it from the startup path.
  5. Six worktree symlinks — copy the targets into ~/.agents/skills so they survive worktree cleanup.
  6. Decide OMP's plugin story. Either accept “everything installed” or give it an explicit set. Right now it inherits Claude's installs while ignoring Claude's decisions.
  7. Delete Copilot's four test fixtures and reconcile Pi's 14-installed-versus-5-declared package drift.
